# Single Stock ETF — флоу для разработки

Экспорт инвест-флоу Freedom Bank (Single Stock ETF: акции дробями 1/100).

## Как открыть
- `index.html` — карта флоу: все экраны по этапам, превью, описание, ссылки на HTML и PNG.
- `prototype/index.html` — живой кликабельный прототип (сразу стартует сценарий SS ETF). `?picker=1` — показать выбор сценария.
- Всё работает локально через `file://`, без сервера и сети.

## Структура
```
index.html          карта флоу
prototype/          живой прототип: index.html, app.css, app.js, media/ (картинки, шрифты SF Pro)
screens/NN-*.html   статичные снимки каждого экрана (DOM + общие стили прототипа)
png/NN-*.png        скриншоты @2x, 390×844
screens.json        список экранов {id, title, note}
tokens.css/.json    цвета прототипа → токены FR-T
```

## Флоу
1. **Онбординг новичка:** сторис → главная новичка «Откройте брокерский счёт — и начните инвестировать» (каталог, долгосрочные инвестиции, прогнозы, портфели известных людей) → «Всё готово к старту» → анкета (шаг 1/2) → документы и подпись (2/2) → «Счёт открывается…» → главная клиента и пуш «Брокерский счёт открыт».
2. **Клиент:** главная клиента (баланс, график, счета, портфель, каталог) → страница бумаги (график, позиция, аналитики, алерты, статистика, обсуждение, новости).
3. **Покупка:** «Торговать» → меню Купить/Продать/Закрыть → ордер (кол-во, цена, сумма, кейпад) → подтверждение свайпом → успех → портфель с тостом.
4. **Продажа:** ордер продажи («продать всё») → подтверждение свайпом → успех.
5. **Вывод** и **D-счёт** — см. раздел «FR DS».

Подарка (акции в подарок) в прототипе больше нет. Вкладка «Крипта» скрыта: в таббаре «Инвест · Поиск · Идеи».
Папки `png/` и `screens/` — снимки предыдущей версии (с подарком и старыми компонентами), актуальный вид — в `prototype/`.

## Бизнес-логика SS ETF
- 1 единица = 1/100 акции (тикер `AAPL/100`), цена за единицу = цена акции / 100.
- Ордер: ввод количества штук; сумма = кол-во × цена. Цена — рыночная (Bid/Ask в шапке).
- Комиссия показывается отдельно в подтверждении; «Итого к списанию / к зачислению».
- Подтверждение — свайп вверх (не кнопка).
- Продажа: ограничение доступным количеством, «продать всё».
